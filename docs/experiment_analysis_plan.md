# Experiment Analysis Plan — Reduced Document Friction

Control keeps the current document flow. Treatment removes one document requirement for pre-specified low-risk applicants. Assignment is random and analysis is intention-to-treat.

Primary metric: contribution margin per assigned application. Secondary metrics: application completion and take-up. Guardrails: fraud, FPD30, default, and complaints. The synthetic implementation reports completion only; it does not claim causal profitability.

The power helper estimates per-arm sample size for an 80%-power, two-sided two-proportion comparison. Launch, continue, and rollback criteria must be defined before examining real outcomes.
